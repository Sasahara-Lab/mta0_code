# Code for the multiple AI advisers paper (MTA0)

Code to reproduce the quantitative figures of the paper — **Fig. 2**
(decoupling and exposure), **Fig. 3** (rate-crossover boundary and disclosure
reference scale), **Fig. 4** (three user-side quantities), **Fig. S1** (phase
diagram) and **Fig. S2** (null-model illustration) — and the theory and
simulation library behind them. Each figure is produced by one script run with
its default parameters. Fig. 1 is a hand-drawn concept diagram and is out of
scope.

The design separates three layers:

- **`mta/`** — an importable library with **no side effects**: the analytical
  closed forms (`mta.theory`, the single source of truth), the simulation engines
  (`mta.simulation`), and the shared plotting style (`mta.viz`).
- **`scripts/`** — entry points: `panel_*.py` draw one panel each (named by
  content); `fig*.py` compose them into the paper figures.
- **`data/`, `figures/`** — outputs. The five paper figures and the pinned
  simulation CSV are committed as reference copies; everything else there is
  regenerated by the scripts.

## Setup and reproduction

```bash
pip install -e .          # installs numpy, scipy, matplotlib, seaborn

cd scripts/figures
python fig2_abcd.py       # paper Fig. 2
python fig3_rates.py      # paper Fig. 3
python fig4_all.py        # paper Fig. 4
python figS1_phase.py     # paper Fig. S1

cd ..
python run_figS2_nullmodel.py       # Fig. S2 step 1: simulate (seed=7, N=400,000)
python figures/figS2_nullmodel.py   # Fig. S2 step 2: plot

python ../tests/test_theory.py      # or, from the repository root: pytest
```

Each `panel_*.py` also runs standalone. `MTA_OUTDIR` overrides the output
directory; `MTA_PDF=1` also writes PDFs.

The chain is deterministic end to end. `run_figS2_nullmodel.py` reproduces
`data/raw/figS2_nullmodel.csv` md5-identically on an independent machine, the
Monte Carlo being pinned by `seed=7` and a fixed draw order (verified
2026-09-22). The five code-generated figures of the manuscript
(`fig2_abcd`, `fig3_rates`, `fig4_all`, `figS1_phase`,
`figS2_nullmodel_illustration`) are numerically identical across machines,
but the rendered PNG/PDF files are byte-identical only when the matplotlib
version and font stack match; verify figures by inspection or regenerate
them in place. The paper embeds the PDF variants (set `MTA_PDF=1`).

Last verified with Python 3.11.15, numpy 2.4.4, scipy 1.17.1, matplotlib
3.10.9 and seaborn 0.13.2 (2026-09-22). The dependencies are left
unpinned in `pyproject.toml`; for exact figure regeneration, install these
versions.

## Numerical conventions

Binomial sums are evaluated in log space, and `K_star` compares the residuals
`1 - P_vis` and `1 - P_agg` in log space; comparing the probabilities directly
in float64 produces spurious crossings once both round to 1. `K_star` returns
`None` for p >= 4/5 (no finite crossover exists; Supplementary Note 5) and
raises `RuntimeError` if `Kmax` is exhausted below 4/5, so the two cases are
never confused. `P_vis` is defined for K >= 4 and returns `0.0` below.
`P_agg` and `K_star` take `tie="fair"` (the paper's convention) or
`tie="strict"` (Supplementary Note 5).
